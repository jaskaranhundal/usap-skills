# Architecture Advisor

System design advisory: ADR generation, trade-off analysis, scalability review, and technology selection guidance.

## When to use

- Making a significant architectural decision and need structured analysis
- Generating an Architecture Decision Record (ADR) for a proposed change
- Evaluating competing design options with explicit trade-off documentation
- Reviewing a system design for scalability and operational concerns

## Quick Start

```bash
python scripts/architecture-advisor_tool.py --help
python scripts/architecture-advisor_tool.py --output json
```

## Skill Level: L3

Produces advisory output only. Generates ADR documents in MADR format for human review and adoption.

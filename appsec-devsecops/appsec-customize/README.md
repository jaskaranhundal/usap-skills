# appsec-customize

Adapts the AppSec chain to a new language or vulnerability class. Walks three forcing questions, emits `CUSTOMIZE.md` the other chain skills read as configuration overrides.

```bash
python3 scripts/appsec-customize_tool.py --output json
python3 scripts/appsec-customize_tool.py --input answers.json --output json
python3 scripts/appsec-customize_tool.py --output human
```

Full methodology in [`SKILL.md`](SKILL.md).

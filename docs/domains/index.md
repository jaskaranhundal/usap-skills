## Where to start

- For a single security alert: route via [`cs-security-analyst`](https://github.com/jaskaranhundal/usap-skills/blob/main/agents/security/cs-security-analyst.md).
- For an active incident: [`cs-incident-responder`](https://github.com/jaskaranhundal/usap-skills/blob/main/agents/security/cs-incident-responder.md).
- For a webapp finding: [`cs-appsec-engineer`](https://github.com/jaskaranhundal/usap-skills/blob/main/agents/appsec/cs-appsec-engineer.md).
- For a cloud / CSPM finding: [`cs-cloud-investigator`](https://github.com/jaskaranhundal/usap-skills/blob/main/agents/security/cs-cloud-investigator.md).
- For a supply chain alert: [`cs-supply-chain-defender`](https://github.com/jaskaranhundal/usap-skills/blob/main/agents/security/cs-supply-chain-defender.md).
- For threat intelligence work: [`cs-threat-intel-lead`](https://github.com/jaskaranhundal/usap-skills/blob/main/agents/security/cs-threat-intel-lead.md).
- For purple team exercises: [`cs-purple-team-lead`](https://github.com/jaskaranhundal/usap-skills/blob/main/agents/security/cs-purple-team-lead.md).
- For board-level reporting: [`cs-ciso-advisor`](https://github.com/jaskaranhundal/usap-skills/blob/main/agents/executive/cs-ciso-advisor.md).
- For program planning: [`cs-security-program-manager`](https://github.com/jaskaranhundal/usap-skills/blob/main/agents/governance/cs-security-program-manager.md).

# Risk & Compliance Domain

Skills in this domain handle enterprise risk quantification, regulatory mapping, and compliance evidence collection.

## Skills

| Slug | Level | Description |
|---|---|---|
| `enterprise-risk-assessment` | L2 | Board-level enterprise risk assessment: risk aggregation, heat maps, risk appetite alignment |
| `risk-threat-modeling` | L1 | STRIDE/PASTA/LINDDUN threat modeling: DFDs, risk scoring (Likelihood × Impact), MITRE mapping |
| `compliance-mapping` | L2 | Maps security findings to regulatory frameworks: GDPR, PCI DSS, HIPAA, SOC 2, ISO 27001 |
| `regulatory-horizon` | L2 | Tracks emerging regulatory requirements and their security control implications |
| `privacy-dpia` | L2 | Data Protection Impact Assessment for GDPR-applicable features and processing activities |
| `cyber-insurance` | L2 | Evaluates cyber insurance coverage adequacy against incident scenarios and risk profile |
| `internal-audit-assurance` | L2 | Internal audit evidence collection: SOC 2, ISO 27001, SOX IT general controls |
| `security-posture-score` | L3 | Cross-domain security posture scoring: aggregates findings into an executive scorecard |

## Workflow: Risk Assessment Pipeline

```
risk-threat-modeling → enterprise-risk-assessment → compliance-mapping → metrics-reporting
```

## Supported Frameworks

- NIST CSF 2.0
- ISO/IEC 27001:2022
- SOC 2 Type II
- PCI DSS v4.0
- GDPR / UK GDPR
- HIPAA Security Rule
- SOX IT General Controls
- CIS Controls v8
